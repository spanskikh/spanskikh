# Release `v0.7.0` Retrospective

## Lessons Learned
- Consolidating shared governance docs (`DEVPROCESS.md`, `RELEASES.md`, `docs/DEFECTS_AND_CAPA.md`, `docs/releases/*`) into `spanskikh/spanskikh` (`CAPA-004` / `CR-020`) eliminates 4x duplication and enforces a single source of truth.
- Meta-testing the doc auditor (`BUG-002` / `CAPA-005` / `CR-021`) closed a blind spot where sub-documents (`docs/releases/*-refine.md`) bypassed Cyrillic checks; all tracked `*.md` files are now scanned recursively.
- Keeping PTY pastes `<= 1.5 KiB` (`CAPA-003`) and Python string literals `<= 85` chars prevents terminal truncation and `ruff E501` loops.

## Rejected Ideas
- Maintaining synchronized copies of `DEVPROCESS.md` and `RELEASES.md` across 4 dev repos was rejected after SHA-256 audit exposed whitespace drift.

## Unlucky Probe-Runs
- Multi-line heredocs `> 1.5 KiB` truncated Mermaid fences in Konsole PTY (`CAPA-003`).
- `_seed_clean_repo` fixtures `< 120` bytes triggered `MISSING_REQUIRED_FILE` until expanded.

## Release Chat Digest
- Delivered `CR-017` (`docs/ENGINEERING_PROFILE.md`), `CR-018` (`spanskikh/spanskikh` showcase), `CR-019` (`CAPA-003`), `CR-020` (`CAPA-004` SSoT migration), and `CR-021` (`BUG-002` / `CAPA-005`).
