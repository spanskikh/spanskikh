# Release Retrospective — `v0.3.0` (`CR-005` .. `CR-008` + `BUG-001` / `CAPA-001`)

Post-release engineering analysis covering lessons learned, rejected ideas, unlucky probe-runs, and key decisions from the `v0.3.0` release session.

## 1. Lessons Learned
- **Stateful Schema Evolution (`BUG-001` / `CAPA-001`):** `CREATE TABLE IF NOT EXISTS` is a silent no-op on existing cluster tables on `rhino`. Every constraint or index invariant requires an explicit idempotent catalog guard (`pg_constraint` / `pg_indexes`) and live `@pytest.mark.integration` verification against stateful databases.
- **Defect Closure Discipline:** Fixing an unexpected defect requires both a regression test (`BUG-001`) and a cross-repository process rule (`CAPA-001` in `docs/DEFECTS_AND_CAPA.md`) before advancing to the next CR.
- **Test Oracle Mutation Verification:** Documentation and static quality gates must be tested against seeded negative counterexamples (`test_doc_auditor_catches_seeded_counterexamples`) to prove non-vacuous detection.

## 2. Rejected Ideas
- **LLM-Only Documentation Gate:** Rejected relying solely on Ollama rubric scoring for CI/CD because CPU inference (`i5-9500`) takes ~100s per repo and is non-portable to GitHub Actions; split into deterministic AST/Markdown structural checks (`-m "not integration"`) plus local Ollama rubric evaluation (`-m "integration"`).
- **Unbounded Prompt Bundles on CPU Inference:** Rejected sending `6000`-character doc bundles with default context windows to `qwen2.5-coder:7b` on `hippo` (`ReadTimeout` at `60s`); bounded context to `2800` chars (`num_ctx=2048`, `num_predict=160`, `timeout=180.0`).
- **Squashing Feature History:** Rejected fast-forward/squash merges in favor of `--no-ff` merge commits preserving CR traceability in `main`.

## 3. Unlucky Probe-Runs
- **Probe 1 (`test_live_gist_concurrency.py` on `rhino`):** First live run committed `2` overlapping bookings (`[10, 14)` and `[12, 16)`) instead of raising `23P01` `ExclusionViolation`, exposing `BUG-001` on pre-existing `v0.1.0` `bookings` table.
- **Probe 2 (`test_live_ollama_doc_rubric_and_counterexample`):** First run timed out (`httpx.ReadTimeout` at `61.2s`) across all 4 repos due to CPU prefill latency on `hippo`; resolved by bounding `num_ctx`/`num_predict` and raising timeout to `180s` (subsequently `100%` green in `99s–125s`).
- **Probe 3 (Terminal Clipboard Paste & Pager Traps):** Large multi-line pastes triggered KDE Konsole paste-warning modals and line flattening, while `git show` opened `less` on `(END)`; resolved via `ShowHugePasteWarning=false`, `core.pager="less -FRX"`, and `CR-009` file-based dev-log artifacts.

## 4. Release Chat Digest
- Closed `BUG-001` (`hostel_ops/storage.py` idempotent `pg_constraint` migration + barrier concurrency test) and established `docs/DEFECTS_AND_CAPA.md` (`CAPA-001`).
- Authored Level-2 `docs/ARCHITECTURE.md` across `abstract-ops`, `interview-ops`, and `hostel-ops`.
- Implemented `tests/test_docs_quality.py` with 7 seeded mutation counterexamples + live `Ollama` rubric grading, tagged `v0.3.0`, and pushed all 4 repositories to GitHub.
