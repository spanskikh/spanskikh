# Release Retrospective — `v0.4.0` (`CR-009`: Dev-Process Auditability, Execution Logging & Release Retrospectives)

Post-release engineering analysis covering lessons learned, rejected ideas, unlucky probe-runs, and key decisions from the `v0.4.0` release session.

## 1. Lessons Learned
- **Logged Execution Wrapper (`scripts/run_logged.sh`):** Capturing split `.stdout`, `.stderr`, and combined `.log` files with ISO-8601 `RUN START` / `RUN END` timestamps eliminates ephemeral terminal scrollback loss and provides verifiable execution evidence for `CHANGELOG.md`.
- **Interactive Shell Safety:** Never include `set -e` in multi-line commands pasted into interactive `bash` shells; use explicit `|| break` loop guards so failed lint/test gates report diagnostics without terminating the terminal session.
- **Line-Length Hygiene in Code Generators:** Automated AST/text injection scripts must wrap generated lines at `<= 100` characters (`ruff` `E501`) before running quality gates.

## 2. Rejected Ideas
- **Committing Raw `.log` / `.stdout` / `.stderr` Files to Git:** Rejected versioning raw execution logs in Git to prevent repository bloat; gitignored `logs/` while versioning deterministic patch/script artifacts in `docs/dev-log/` and release retrospectives in `docs/releases/`.
- **Informal Release Summaries Without Automated Enforcement:** Rejected manual-only retrospectives in favor of enforcing `vX.Y.Z-retrospective.md` and its 4 mandatory sections directly inside `tests/test_docs_quality.py` (verified via the `missing_retrospective_section` negative counterexample).

## 3. Unlucky Probe-Runs
- **Probe 1 (`set -e` in Interactive Konsole Session):** Pasting `set -e` at the top of a bash loop caused Konsole to close immediately when `ruff` returned exit code `1` on an `E501` line; resolved by switching to `|| break` in interactive commands.
- **Probe 2 (`E501` Line-Length Violations in `test_docs_quality.py`):** Injected `retro_files` comprehension (`123` chars) and `required_secs` tuple (`106` chars) tripped `ruff` `E501` twice before wrapping into multi-line tuples.

## 4. Release Chat Digest

- Created `docs/dev-log/` artifact trail and `docs/releases/v0.3.0-retrospective.md`.
- Upgraded `tests/test_docs_quality.py` to 8 seeded mutation counterexamples, verified green `cr009_final_gate`, and tagged `v0.4.0`.
