# Release `v0.8.0` Retrospective

## Lessons Learned
- Grammar-constrained JSON Schema decoding in Ollama (`DocRubricScore.model_json_schema()` + `temperature=0.0`, `CAPA-006`) eliminates stochastic field omissions and length overflows (`BUG-003`) at token sampling time.
- CPU-only inference of `qwen2.5-coder:7b` (`5.07 GiB` on `hippo` `i5-9500`) requires `timeout >= 180.0s` for cold GGUF load + prefill.
- Host-side live integration tests against container-configured `.env` files require explicit `127.0.0.1` DSN/URL and local `AUDIT_DB_PATH` overrides.

## Rejected Ideas
- Prompt-only length hints (`"concise string under 250 chars"`) under plain `"format": "json"` were rejected after `qwen2.5-coder:7b` omitted `interviewer_market_value`.

## Unlucky Probe-Runs
- `httpx.ReadTimeout` at `60.0s` during cold model load on `hippo` CPU (`BUG-003`).
- `psycopg.OperationalError` and DuckDB `/app/data/` path mismatch when running integration tests outside Docker without host overrides.

## Release Chat Digest
- Delivered `CR-022` (cross-cluster Z3 RAM budget & 12-tool namespace disjointness + `CycloneDX` SBOM CI gate) and `CR-023` (`BUG-003` / `CAPA-006` + `139/139` offline + live integration sign-off).
